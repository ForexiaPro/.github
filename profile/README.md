## Forexia

Free trading tools and data from [Forexia Academy](https://forexiapro.com/?via=github-profile), the trading academy at forexiapro.com: CFTC Commitments of Traders data, a position size calculator, a currency strength meter and session clock, a trading journal, a Discord bot and a browser toolbar. Each works on its own, with no account and no key.

**[forexiapro.com](https://forexiapro.com/?via=github-profile)** · [Trading tools](https://forexiapro.com/tradingtools?via=github-profile) · [COT report guide](https://forexiapro.com/cot-report/?via=github-profile)

### Open source and open data

| Repository | What it is |
| --- | --- |
| [cot-data](https://github.com/ForexiaPro/cot-data) | The CFTC's Commitments of Traders report for FX futures and gold as clean CSV and JSON, updated each Friday: net positions, the change on the week and net as a % of open interest; `pip install forexia-cot` / `npm install forexia-cot` |
| [tradingview-cot](https://github.com/ForexiaPro/tradingview-cot) | A TradingView indicator: net non-commercial and commercial positions for the chart's currency or gold |
| [position-size](https://github.com/ForexiaPro/position-size) | One position size calculation as an npm library (`forex-position-size`), an embeddable widget and an MT5 script that sizes from the chart's stop line |
| [strength-sessions](https://github.com/ForexiaPro/strength-sessions) | A currency strength meter and a forex session clock, as website widgets and MT5 indicators |
| [traders-toolbar](https://github.com/ForexiaPro/traders-toolbar) | A browser toolbar: the next central bank decision with a countdown, the session clock, this week's COT positioning and the latest signal chart. No account, no tracking |
| [trading-journal](https://github.com/ForexiaPro/trading-journal) | A trading journal template for Google Sheets, Notion and Obsidian: R-multiples, the session and news window of each trade, a prop firm rules panel |
| [macro-desk](https://github.com/ForexiaPro/macro-desk) | A Discord bot: `/rate fed`, `/next`, `/odds boe`, `/cot eur`, `/size`, `/signal eurusd`. Hosted, or self-host it |
| [awesome-forex](https://github.com/ForexiaPro/awesome-forex) | A curated list of free forex data, libraries, charting, backtesting and education |

All of them on one page: [forexiapro.github.io](https://forexiapro.github.io/).

Trading foreign exchange carries a high level of risk. These tools are for information and education, not investment advice.
